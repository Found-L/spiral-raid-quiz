# 剑灵巅峰服 · 螺旋寺院机制考核

国内访问：<https://www.lysue.com/spiral-raid-quiz/>

GitHub 入口：<https://found-l.github.io/spiral-raid-quiz/>

免注册填写昵称后即可答题。题库共 87 道客观题，覆盖灼热剑与酷寒剑、超魔灵、黑风魔女，以及主 T、控制、挡球、加血、业火、炸弹和蜘蛛等位置。完成后自动评分并展示逐题解析；综合榜单每人显示已完成的最新题库中的最高分，同分先比较用时。

首页的三个机制图解可打开首领详情，按触发阶段查看俯视图、站位、路线和岗位分工。部分题目配有场景图。

题目依据螺旋寺院在巅峰服上线后的实战资料和提供的魔女试卷编写。题目直接描述阶段、机制和操作；涉及团队分工时，按题干中的团队安排作答。实战请以当前版本和团长安排为准。图为分工示意。

## 昵称与成绩

- 填写昵称即可答题。系统自动分配唯一的榜单编号，同名玩家可以用编号区分。
- 排行榜显示昵称、编号和成绩。修改昵称会保留原编号和成绩。榜单编号可以公开分享。
- “我的答题记录”可以查看历次已上传的分数、正确题数、用时和上传时间，包括旧版题库记录。记录只对拥有对应身份的浏览器开放。综合榜单保留旧版成绩，一旦该身份完成新版，改用新版成绩，即使分数更低；同一题库内保留最高分。同分按用时由短到长排列，还相同时按上传时间排序。旧成绩没有保存用时，显示“未记录”，同分时排在有记录的成绩之后。可切换查看各版本单独的榜单。
- 从开始本轮答题到交卷计时，包括关闭网页或离开页面的时间。上线前已作答但没有开始时间的未交卷进度和旧成绩均显示用时未记录；计时来自浏览器，仅供学习参考。
- 成绩服务暂时无法连接时，新用户仍可在当前浏览器输入昵称并答题。成绩先保存在本机，重新连接后上传；未上传前不会出现在共享排行榜。身份码恢复需要成绩服务可用。
- 若成绩保存在 GitHub 网址，使用原浏览器打开并刷新原网址，点击顶部“转移到国内网址”，在新页面确认后会用原身份同步待上传成绩。转移前关闭国内网址的其他标签页。已同步的历史记录继续跟随原身份；旧版成绩在未完成新版前显示在综合榜单中。
- 如浏览器阻止弹窗，可在原网址下载迁移文件，再到国内网址的“修改资料 → 导入迁移文件”选择文件。迁移文件包含可修改资料的身份信息，不要发送给他人；确认转移成功后妥善删除。国内网址的已有其他资料会保留，可在“修改资料 → 切换本机保留的资料”中切换。原网址的数据不会因转移而删除。
- 答题进度保存在当前浏览器。题库更新时，未修改题目的作答会保留，已修改的题目需要重新作答。更换设备或清除浏览器数据前，可在资料弹窗中备份身份码，之后用它恢复原有身份。身份码具有修改资料的能力，请勿公开。
- 可在资料弹窗中删除自己的线上资料和成绩。题目与答案公开，排行榜仅用于团队学习，不能作为防作弊考试。

## 项目结构

- `index.html` 是包含样式、脚本、题库和插图的独立网页，部署在 GitHub Pages 和国内服务器。
- `template.html`、`style.css`、`detail.css`、`app.js`、`guide.js`、`diagrams.js` 和 `questions.json` 是网页源码。修改题库时先运行 `python build_questions.py`，再运行 `python build_page.py` 生成网页并同步国内服务题库。
- `domestic-backend/` 是国内共享计分与排行榜服务；两个入口使用同一份 SQLite 数据库。`banks/` 保留旧版题库，以接收旧版页面或离线待上传的成绩。旧的 Sites 接口负责兼容旧版网页。
- `backend-source/` 是 Sites 兼容接口的源码快照，旧接口转发到国内成绩服务。
